# iPhone-Duo-MagSafe-Wallet
Instructions and files for the a 3d printed wallet that uses a trimmed back panel from an existing Apple MagSafe Wallet.
Below are instructions on how to do this. This will fit about 2-3 cards. 

1. Use an old Apple Magsafe Wallet or any from a third party. I used an old Apple one (didn't want to ruin my current one in case this didn't work out)
2. Remove the pocket on the wallet.
3. Cut the base so it fits within the footprrint of the Duo, roughly 63 x 84 mm, the 63 is the stock width, I only trimmed the height from the bottom edge. I used a regular ruler that had cm, roughly 8.4cm for the height (I eyeballed it when cutting then measured to create the 3d printed wallet).
4. Make sure to clean the resulting base plate well of any glue from the removed pocket. Leave the spring tab on there as we will use to hold the cards in place in the new wallet.
5. Print the stl file. I used PLA.
6. Glue the wallet back to the back plate. Note that it should sit on the side of the back plate, the side that has depth to it, make sure to insert the spring tab through the similarly shaped hole. I used regular PLA glue for all of it.
7. Glue the top half of the wallet.
8. Set something have on it like a book
